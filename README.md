# Metroid II — First Person

An unofficial experiment in exploring the world of **Metroid II: Return of Samus** through a first-person camera, while retaining the original Game Boy gameplay and atmosphere.

**This repository is a documentation template. No playable build, game data or extraction tool is published here yet.**

## Bring your own game

You will need your own supported copy of the original game. Original graphics, maps, sprites, music and sound will be extracted or decoded **locally from your copy**. This repository will not supply ROMs or extracted game assets. Project-created rendering code and procedural presentation are separate from that original content.

The planned setup never requires uploading a game file to a website or sending it to a maintainer. See [setup](docs/setup.md) and the [asset policy](docs/asset-policy.md).

## The experience

- Dark exploration, tight passages and broad caverns that follow the original chamber shapes.
- Original enemy sprites and music, with an optional live Game Boy inset.
- Original movement, progression, damage and firing restrictions beneath the new view.
- Chamber lighting, source-directed cannon movement and clear combat feedback.

Movement remains on the original two-dimensional plane. Looking around does not add independent third-axis traversal or unrestricted FPS aiming.

## Status

The local development prototype is at **0.11**. Its reviewed ordinary-input route reaches 35 of the original 47 Metroid defeats, including all three Zetas and the first Omega, and returns to an original save station. This is a development milestone, not a public release or a completed full-game claim.

Desktop work has focused on Apple Silicon macOS. Brief area-entry hitches remain. Switch work is deferred; no Switch build or performance result is announced.
