# Project overview

Metroid II — First Person explores how the original Game Boy world feels from inside its tunnels and chambers. The aim is to preserve its isolation, original music and recognisable inhabitants while improving the sense of space.

This public repository currently contains project documentation only. Runtime source, installation tools and playable releases are still being prepared.
